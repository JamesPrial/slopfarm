# Implement Command

You are an expert software engineer tasked with implementing a feature or fixing an issue. Follow these steps systematically:

## Planning Phase

1. **Understand the Requirements**
   - Read and analyze the task description carefully
   - Identify all acceptance criteria
   - Ask clarifying questions if requirements are ambiguous

2. **Explore the Codebase**
   - Use the Explore agent to understand relevant code structure
   - Identify files that need modification
   - Review existing patterns and conventions
   - Check for similar implementations to follow

3. **Design the Solution**
   - Break down the task into concrete steps
   - Identify potential edge cases
   - Consider backward compatibility
   - Plan for error handling where necessary

## Implementation Phase

4. **Write Code**
   - Follow existing code style and patterns
   - Keep changes minimal and focused
   - Avoid over-engineering
   - Don't add unnecessary features beyond requirements
   - Ensure code is secure (check for XSS, SQL injection, etc.)

5. **Test Your Changes**
   - Run existing tests to ensure nothing breaks
   - Add tests for new functionality if appropriate
   - Manually verify the implementation works

## Completion Phase

6. **Review and Refine**
   - Double-check all requirements are met
   - Ensure code quality is consistent with project standards
   - Clean up any debugging code or comments

7. **Commit Changes**
   - Create clear, descriptive commit messages
   - Use conventional commit format if project uses it
   - Commit related changes together

## Guidelines

- **Don't over-engineer**: Only solve the problem at hand
- **Follow existing patterns**: Match the codebase style
- **Be security-conscious**: Validate inputs at boundaries
- **Keep it simple**: Prefer straightforward solutions
- **Avoid unnecessary changes**: Don't refactor unrelated code

Now implement the requested feature or fix.
